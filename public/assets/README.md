# CycleCoreLIMS Logo Instructions

## How to Add Your Logo

1. **Place your logo file** in the `public/assets/` directory
2. **Name your logo file** `cyclecore-logo.png` (or `cyclecore-logo.jpg`, `cyclecore-logo.svg`)
3. **Recommended dimensions**: 
   - Height: 64px for login page
   - Height: 32px for sidebar
   - Width: Auto (maintains aspect ratio)

## Supported Formats
- PNG (recommended for transparency)
- JPG/JPEG
- SVG (for vector graphics)

## Logo Fallback
- If the logo fails to load, the system will automatically fall back to the default text/icon
- This ensures the application always works even without a logo

## Current Logo Path
- Login page: `/assets/cyclecore-logo.png`
- Sidebar: `/assets/cyclecore-logo.png`

## Testing
After placing your logo:
1. Restart the development server
2. Clear browser cache if needed
3. The logo should appear on both the login page and sidebar

## Logo Branding Guidelines
- Keep it professional and clean
- Ensure good contrast with the white background
- Maintain readability at small sizes
- Consider using your company/organization colors
